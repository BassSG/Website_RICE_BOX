ถ้าต้องการควบคุมไม่ให้ผู้ชมออกไปแพลตฟอร์มอื่นมากขึ้น แนะนำ Cloudflare Stream, Bunny Stream หรือ Vimeo privacy เพราะควบคุม player, domain restriction และลิงก์ภายนอกได้ดีกว่า YouTube

YouTube Invisible คืออะไร?

ใน YouTube จะเรียกสถานะนี้ว่า Unlisted หรือไม่เป็นสาธารณะ คนที่มีลิงก์จึงดูได้ แต่ไม่ถูกค้นหาเจอง่าย ส่วน Private จะดูได้เฉพาะบัญชีที่ได้รับสิทธิ์เท่านั้น

ผู้ชมจะกดออกไป YouTube ได้ไหม?

ถ้าใช้ YouTube embed ยังมีข้อจำกัดจากตัว player เอง จึงลดการไหลออกได้แต่ปิดทั้งหมดไม่ได้ ถ้าต้องการคุมเข้มควรใช้บริการวิดีโอที่รองรับ domain restriction

เพิ่มบทเรียนใหม่ทำยังไง?

เพิ่ม object ใหม่ใน array lessons ของไฟล์ js/app.js ใส่ชื่อบทเรียน เวลา Video ID รายละเอียด prompt และไฟล์ประกอบได้ทันที
